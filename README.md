## What's here

- **Home** (`index.html`) - single-page portfolio: hero, metrics, experience, skills, projects, homelab, certifications, contact
- **Writing** (`blog/`) - field notes on technical operations and applied AI (4 posts)
- **Case studies** (`case-studies/`) - deep dives on endpointwatch and rackpulse
- **Resume** (`resume.pdf`) - current platform resume
- **Assets** (`css/site.css`, `fonts/`, `og.png`) - shared stylesheet, self-hosted Geist fonts, social share image

## Tech

Static HTML, CSS, and a few lines of vanilla JS. No frameworks, no trackers, no cookies. Fonts are self-hosted (Geist + Geist Mono). Deploys automatically from `main` via GitHub Pages with free TLS.

## Update

Edit, commit, push to `main`. GitHub Pages rebuilds in about a minute. Keep `resume.pdf` in sync with the master resume.
