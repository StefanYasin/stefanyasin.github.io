What a small business should actually monitor

Five things, not five hundred. Monitoring works when it pages the right person about the right failure.

Every monitoring dashboard a small business buys starts the same way: five hundred widgets, all green, nobody watching. Then the server dies on a Saturday and the owner finds out from a client.

Monitoring is not about seeing everything. It is about deciding what deserves to interrupt someone, and who that someone is.

I learned this in a plant, the expensive way. We watched everything: network gear, servers, building systems, production equipment. Everything pinged everyone, so nothing mattered to anyone. An alert with no owner is a dashboard, not an alert. The fix was not more tools. It was five categories and one named owner per category.

For a small business, the five things that actually matter:

  1. Backup age, not backup status. How old is the newest good copy? If that number grows, something quietly stopped working.
  2. Disk health and space. Drives fail slowly before they fail fast. The slow part gives you weeks.
  3. Power. A UPS on battery is a countdown. Knowing the minute it starts is the difference between a clean shutdown and a scramble.
  4. Reachability from outside. A ping from inside the network proves nothing. The question is whether a client can reach you right now.
  5. The heartbeat. Something outside your building should notice if your building goes quiet. If your monitoring lives on the server it watches, silence looks exactly like health.

And the rule that makes it stick: every alert has one owner. If nobody can say “I get woken up for this,” it is not an alert, it is decoration.

This is the same model I run for my own fleet of automation agents, with a dashboard called agentpulse, and it is the first thing we install at Cloud and Cable. Five things, one owner each, and an inbox that stays quiet until something real happens.
